# SafeHer — Women's Safety App

SafeHer is an installable progressive web app focused on quick access to safety tools:

- One-tap SOS and emergency calling
- Trusted contacts and location sharing
- Fake call mode
- Evidence recording
- Offline-friendly app shell
- Translation and safety utilities

## Run locally

This is a static web app and does not require a build step. Serve the project over
HTTPS (or use a local development server) so browser permissions and PWA features
work correctly.

For example:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.
